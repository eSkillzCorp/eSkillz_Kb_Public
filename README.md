# eSkillz Public Knowledge

This repository will contain eSkillz business knowledge approved for public
use, in the [Open Knowledge Format (OKF) v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md).

It is a **distribution repository**. Content is authored, reviewed, and
approved in eSkillz's private knowledge repository and arrives here only
through reviewed pull requests from the controlled publishing process. Do not
edit files here directly.

No knowledge has been published yet.

This initial commit is a one-time repository initialization, made directly
on `main` because a pull request needs an existing base branch. All later
changes use pull requests.
