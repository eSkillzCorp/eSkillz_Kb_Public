# eSkillz Public Knowledge

This repository contains eSkillz business knowledge approved for unrestricted
public use. It is published in the [Open Knowledge Format (OKF) v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md):
a directory of Markdown files with YAML frontmatter that people, websites,
search systems, and AI agents can read without special tooling.

## How to use it

- Start at [`knowledge/index.md`](knowledge/index.md) and follow the area indexes.
- Each concept's frontmatter tells you what it is (`type`), whether it is
  current (`status`, `stale_after`), and how it was produced and checked
  (`generated`, `verified`, `sources`).
- Treat a concept as current only when `status` is `stable` and the present
  time is before `stale_after`.
- [`knowledge/log.md`](knowledge/log.md) records what changed and when.
- [`publication.json`](publication.json) records the source revision and a
  content hash for every published concept.
- [`MANIFEST.yaml`](MANIFEST.yaml) describes this repository for machines;
  [`AGENTS.md`](AGENTS.md) and [`llms.txt`](llms.txt) guide AI agents.

## How it is maintained

This is a **distribution repository**. Content is authored, reviewed, and
approved in eSkillz's private knowledge repository and published here only
through reviewed pull requests generated by eSkillz's publishing process.
Do not edit files here directly; direct edits fail validation and are
overwritten by the next publication. `tools/validate_public.py` checks every
change independently.

To report an error, open an issue in this repository.
